2.2Configure fixed base stations

2.2.1 Open the serial port assistant tool
After opening the serial port assistant, select the port number corresponding to
the RTK982 module that needs to be configured as a base station . My fixed base
station configuration here is com15. Send the following 8 commands in sequence:
mode base time 60
rtcm1006 com2 10
rtcm1033 com2 10
rtom1074 com2 1
rtcm1124 com2 1
rtcm1084 com2 1
rtcm1094 com2 1
saveconfig

2.3 Configure the mobile station
2.3.1 Open the UPrecise software again, and then select the com port
corresponding to the RTK-982 that needs to be set as the mobile station to
connect. Here I use com11, and then go to the arrow position in the figure below
to set the mobile station working mode, and click Send. Then wait for the
difference.

4. Check the differential positioning connection status
When the positioning type of the red frame position in the figure below is RTK
Fixed, it means that the fixed solution has been entered, and the positioning
accuracy is at the centimeter level. For other statement parsing, please refer to
the protocol.
Wait for the status type to change. When RTK Fixed appears, the connection is
successful.
